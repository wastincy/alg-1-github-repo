# alg-1-github-repo
Лабораторная работа 1
Установка git: https://git-scm.com
Установить компилятор C++: https://github.com/brechtsanders/winlibs_mingw/releases/download/14.2.0posix-18.1.8-12.0.0-ucrt-r1/winlibs-x86_64-posix-seh-gcc-14.2.0-llvm-18.1.8-mingw-w64ucrt-12.0.0-r1.zip
Добавить в системные переменные среды путь к папке с компиляторами: C:\mingw64\bin
Выполнить компиляцию (1.cpp - название файла): g++ 1.cpp -o app
Запустить программу: ./app

Файлы в LR1:
da.cpp - Hello world!
2.cpp - создание программы по блок-схеме
3.pulm - создание uml диаграмм
umldiag - uml диаграмма с потоками

Файлы в папке potoki:
potoki - 3 файла хранящие конспект лекции как обращаться с потоками
zadanie - вычисление суммы элементов массива в одном и не одном потоке

Файлы в папке matrix:
matrix - файл с программой для сложения и вычитания векторов и матриц
mat1, mat2 - текстовый файл с информацией о матрице
vec1, vec2 - текстовый файл с информацией о векторе
log - логи

Файлы в папке slay:
slay, oop_slay - программа решения СЛАУ
temp - файл с температурой

Файлы в папке graf:
graf - программа с алгоритмом Дейкстры и поиском 
vertices - первое значение вершина для начала обхода, второе - вершина окончания графа, третье - для Дейкстры

Файлы в папке fft:
fft.cpp - реализация быстрого преобразования Фурье
input - входные данные
res - результаты
